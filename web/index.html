RULES, WITHOUT SCRIPTS

Make it your kind of game.

Start with a ruleset

Event → conditions → effects

Built-in modes use these same rules. Score and time limits apply to every match. Each rule runs once per event; score events have bounded recursion.

Rule reference

Events: match_started, player_spawned, player_killed, player_entered_zone, player_left_zone, player_picked_up_item, player_dropped_item, timer_elapsed (once/second), score_changed, flag_captured, hill_held.

Conditions: opponent, alive, carrying_flag, team {team}, score_at_least {value}, time_at_least {seconds}, zone_owned.

Effects: add_score {amount, team}, end_match, respawn, give_weapon {weapon}, remove_item, reset_flags, announce {text}. Every condition/effect has a "type" field.
